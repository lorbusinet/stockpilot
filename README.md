# Mes programmes

Dépôt regroupant plusieurs programmes, chacun dans son propre dossier avec son README.

| Programme | Description |
|---|---|
| [StockPilot](stockpilot/) | Gestion commerciale (stock, commandes, clients, analytique) avec toute la logique métier dans SQLite, exécuté dans le navigateur via WebAssembly |

## Ajouter un programme

1. Créer un dossier à la racine (ex. `mon-programme/`) avec ses fichiers et un `README.md`.
2. Ajouter une ligne dans le tableau ci-dessus.
3. `git add mon-programme README.md && git commit -m "Ajout de mon-programme" && git push`
